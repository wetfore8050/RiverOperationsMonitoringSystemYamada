山田川 河川監視プロトタイプ v2

■変更点
1. 水位観測点のデータURLからJSONをfetch。
2. 直近12時間をChart.jsで描画。
3. A方式はdataをmとして使用。
4. B方式は「氾濫発生までの水位(cm)」なので -data/100 としてmに変換。
5. 基準水位をグラフ内に水平線として表示。
   A 緑 / B 黄 / C 赤 / D 紫 / E 黒 / X 水色
6. カメラは「直近」「約30分前」「平常時」を時刻からURL自動生成。
7. スマートフォン表示にも対応。

■重要
ブラウザから別ドメインのAPIをfetchするため、実際のGitHub Pages等で動かす場合は、
茨城県側のCORS設定によって取得できない可能性があります。
その場合は「自分のサーバー/Cloudflare Worker等を中継する方式」に変更する必要があります。

また、Chart.jsのannotation機能を使用するため、CDNから追加ライブラリを読み込んでいます。
